# จริยธรรมของโครงงาน

Market IDS เป็นต้นแบบเพื่อการศึกษาในวิชา CPE102 เอกสารนี้ขยายความจากหัวข้อ 15 ของ spec ว่าระบบทำอะไรได้ ทำอะไรไม่ได้ และเราตั้งใจไม่ทำอะไร

## 1. ไม่ซื้อขาย ไม่ใช้กุญแจ

- ไม่มีโค้ดส่งคำสั่งซื้อขายเลย และไม่มีที่ให้ใส่ API key
- ระบบติดต่อได้เฉพาะเครื่องบริการข้อมูลสาธารณะของ Binance (`data.binance.vision`, `data-api.binance.vision`, `data-stream.binance.vision`) และ `raw.githubusercontent.com` (สำหรับโหลดบันทึกเหตุการณ์ของ Hu et al.) ตัวรับข้อมูลสดยอมเชื่อมต่อเฉพาะเครื่องเหล่านี้และไม่ตามการ redirect
- ไม่ใช่คำแนะนำการลงทุน และไม่ทำนายราคา

## 2. ไม่กล่าวหาใคร

- การเตือนทุกครั้งใช้คำว่า "พบความผิดปกติทางสถิติ" ไม่บอกว่ามีคนปั่นราคา และไม่บอกว่าใครทำ
- ข่าวใหญ่ การลิสต์เหรียญ หรือคำสั่งซื้อขายขนาดใหญ่ที่สุจริต ก็ทำให้ตลาดผิดปกติได้ การเตือนจึงเป็นแค่ "ช่วงเวลาที่ควรเข้าไปดู" ให้คนตรวจต่อเสมอ
- ข้อมูลสาธารณะไม่มีตัวตนของผู้ซื้อขาย และเราไม่พยายามระบุตัวบุคคลหรือบัญชี ซึ่งเป็นเงื่อนไขของการใช้ข้อมูล Binance Vision ด้วย
- ตัวเขียนคำอธิบายภาษาไทยมีรายการคำต้องห้าม (เช่นคำที่กล่าวหาหรือฟันธง) และชุดทดสอบตรวจทุกข้อความ

## 3. ตัวเลขต้องพูดตรง

- คะแนนรวมของ Chief คือ "anomaly p-value" หรือ "ความหายากเทียบตลาดปกติ" ไม่ใช่ความน่าจะเป็นที่มีการปั่นราคา
- รายงานไม่ใช้ accuracy และไม่ใช้ F1 แบบ point-adjust เพราะทำให้ผลดูดีเกินจริงเมื่อเหตุการณ์มีน้อย ตัวเลขหลักคือ recall ต่อเหตุการณ์ และจำนวนการเตือนผิดต่อสัญลักษณ์-วัน
- ตัวเลขทุกตัวมีป้ายที่มา (REAL / SEMI-SYN / SYN) และรายงานสร้างจากการทดลองทุกครั้งที่บันทึกไว้ ไม่เลือกเฉพาะผลที่ดี
- ถ้า AI ไม่ชนะวิธีพื้นฐาน เราเขียนลงรายงานตรงๆ

## 4. Red-Team ใช้กับข้อมูลเก่าหรือข้อมูลจำลองเท่านั้น

- การใส่เหตุการณ์ปั่นราคาจำลองทำได้เฉพาะโหมด replay และ sim
- ในโหมดสด ระบบปฏิเสธเสมอ (`EthicsError` ในโค้ด และ API ตอบ 403) มีชุดทดสอบยืนยัน
- เหตุการณ์จำลองแก้ไขเฉพาะสำเนาในหน่วยความจำของการเล่นซ้ำครั้งนั้น ไม่เขียนทับข้อมูลจริงในเครื่อง
- ป้ายของเหตุการณ์จำลองติดว่า SEMI-SYN หรือ SYN เสมอ ไม่ปนกับป้ายจริง

## 5. ข้อมูลและสัญญาอนุญาต

- ข้อมูล Binance Vision ใช้แบบไม่แสวงหากำไร พร้อมระบุที่มา (CC BY-NC-SA 4.0)
- บันทึกเหตุการณ์ของ Sapienza (MIT) เก็บในโปรเจกต์พร้อมสัญญาอนุญาต ส่วนของ Hu et al. ไม่มีสัญญาอนุญาต จึงไม่แจกจ่ายต่อและไม่เก็บใน git
- รายละเอียดอยู่ใน `NOTICE.md`

## 6. ความปลอดภัยของเครื่องที่รัน

- API ไม่มีระบบล็อกอิน `idsai serve` จึงเปิดที่ `127.0.0.1` (เฉพาะเครื่องตัวเอง) เป็นค่าเริ่มต้น ถ้าเปิดให้เครื่องอื่นเข้าถึง ระบบจะเตือน
- API รับเฉพาะคำขอที่ระบุชื่อเครื่องเป็น `127.0.0.1`, `localhost`, `[::1]` หรือ host ที่สั่งเปิด (กันการโจมตีแบบ DNS rebinding) และปฏิเสธคำขอ POST หรือ WebSocket ที่มาจากเว็บไซต์อื่น
- ไฟล์โมเดล (`models/`, `data/demo/`) เป็น pickle ให้โหลดเฉพาะไฟล์ที่สร้างเองในเครื่อง ห้ามรับไฟล์โมเดลจากคนอื่น

## 7. สิ่งที่ผู้ใช้ควรทำ

- ใช้ผลการเตือนเป็นจุดเริ่มต้นของการตรวจสอบ ไม่ใช่ข้อสรุป
- ไม่นำผลไปกล่าวหาบุคคล ไม่ใช้เป็นหลักฐานทางกฎหมาย และไม่ใช้ตัดสินใจลงทุน
- อ่าน `docs/DATA_LIMITATIONS.md` ก่อนนำตัวเลขใดไปอ้าง
